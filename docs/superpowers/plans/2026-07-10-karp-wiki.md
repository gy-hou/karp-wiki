# karp-wiki v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把现有 starred 仓库 `chatgpt-advanced-prompts` 就地改造成通用型本地知识库一键搭建模板仓库 **karp-wiki**,交付一个 clone 即用、Claude Code 与 Codex 双端可用、支持多模态录入的脚手架。

**Architecture:** Karpathy 三层模型(`raw/` 只读 → `wiki/` LLM 维护 → `CLAUDE.md`/`AGENTS.md` 规范)。一键搭建逻辑抽成 agent 无关的 `setup-flow.md`,两端共享;日常 ingest/query/lint 由宪法承接;可视化 v1 只留数据契约文档接口。

**Tech Stack:** 纯 Markdown + YAML frontmatter;无构建、无依赖(v1);目标运行时为 Claude Code / Codex;工具契约引用 `git`、`rg`(ripgrep)、可选 Obsidian。

## Global Constraints

- 产品/仓库名:**karp-wiki**(GitHub 端最后重命名,自动重定向保 star)。
- 语言:中文为主 + 英文兼容(README 双份;技术术语/目录名用英文)。
- `raw/` 只读铁律:任何 agent 永不改写 raw 内容。
- frontmatter 契约(每页最小通用集,字段与顺序固定):
  ```yaml
  ---
  id: <kebab-case-唯一标识>
  type: concept | entity | source | output
  title: <标题>
  tags: [<标签>]
  sources: [<关联 source id>]
  created_at: 2026-07-10
  updated_at: 2026-07-10
  ---
  ```
- 内链统一用 `[[wiki-links]]`。
- 每次操作同步更新 `wiki/index.md` 与 `wiki/log.md`(双维护)。
- `wiki/index.md` 每页一行:`- [[id]] — 一句话摘要`。
- `wiki/log.md` 每条格式:`## [YYYY-MM-DD] ingest|query|lint | <标题>`。
- 通用类目:`concepts/` `entities/` `sources/` `outputs/`。
- 多模态 raw 子目录:`text/` `screenshots/` `photos/` `audio/`。
- 不写可跑脚本(可视化、OCR、转写留 v2);示例用占位素材,不含真实私密内容。
- 保留原仓库 `.git` 与 `LICENSE`。
- 参考实现只读来源(不修改、仅借鉴):`~/Documents/english-learn-database`、`~/Library/Mobile Documents/com~apple~CloudDocs/Karp-wiki-prompt.txt`。
