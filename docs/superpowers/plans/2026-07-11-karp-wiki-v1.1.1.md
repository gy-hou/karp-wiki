> **给执行者:** REQUIRED SUB-SKILL —— 用 superpowers:subagent-driven-development(推荐)或 superpowers:executing-plans 逐任务执行。步骤用复选框(`- [ ]`)跟踪。
>
> **本文取代 `2026-07-11-karp-wiki-v1.1.md`。** v1.1 架构方向已通过复核,但第二轮 Codex 复核发现 9 个可复现的执行级 bug;本版逐条修复。修复清单见文末 "v1.1 → v1.1.1 变更映射"。

**Goal:** 把已迁移完成的 `karp-wiki` 仓库做成可公开发布的通用本地知识库模板:Claude Code 与 Codex **双端 native skill** 自动发现、纯 Markdown 资产、一份**可真实先红后绿测试**的确定性内核(`kb.mjs`)保证幂等/去重/安全/可校验,支持文本、真实图片、音频转写录入,并有**可执行的隐私机制**与 CI gate。

**Architecture:** Karpathy 三层模型(`raw/` append-only → `wiki/` LLM 维护 → `AGENTS.md`/`CLAUDE.md` 规范)。规范唯一正文是 `AGENTS.md`,`CLAUDE.md` 用官方 `@AGENTS.md` 导入。一份 canonical Agent Skill 在 `skills/kb-setup/`,由 `scripts/sync-skills.mjs` 生成 `.claude/skills/kb-setup/` 与 `.agents/skills/kb-setup/` 两份**字节一致**镜像(GitHub Actions CI 校验)。状态与断点由 `.karp-wiki/config.json`(`state` + `setup.completed_steps`/`current_step`,原子写)驱动,setup 幂等可 resume。确定性内核 `kb.mjs` 提供 `check / reindex / build-graph`,`check`/`build-graph` fail-closed 非零退出。可视化 UI 留 v2,但 v1 产出可消费的 `graph.json`。

**Tech Stack:** 纯 Markdown + YAML frontmatter;**Node ≥ 20**(仅标准库,零外部依赖);Node 内置 `node --test`;GitHub Actions;`git`(状态/tracking 检测);可选 `rg`。目标运行时 Claude Code / Codex。

## Global Constraints

- 产品/仓库名:**karp-wiki**(定位:公开开源发布 = "内含 project-scoped skill 的 GitHub Template";v1 **不**声称可安装进任意已有仓库)。
- 从**当前已迁移基线**开始;不复制/删除旧 `chatgpt-advanced-prompts` 路径(已不存在)。
- **KB 根定位契约(F2 修复;git-optional):** `kb.mjs` 根解析顺序 = `--root <dir>` → `git rev-parse --show-toplevel` → **`cwd`(仅当 `cwd/wiki/` 存在)** → 都失败则 **fail-fast 报错退出**。**禁止**静默 fallback 到脚本目录(F2 根因)。cwd fallback 让无 git 的 `local-only` 用户从库根跑 `npm run check` 零摩擦;它只在 cwd 确实像知识库(含 `wiki/`)时才生效,不会跑错目录。所有 heredoc/命令仍用 `git rev-parse --show-toplevel` 定位,**禁止硬编码用户绝对路径**。git 因此只在 `private-git`/`public-git` 模式与 GitHub Template 分发时才是硬依赖。
- **raw_path 契约(F1 修复):** `raw_path` **永远相对于 KB 根**(即 `validate(pages, root)` 的 `root`)。fixtures/examples/真实库一律写 `raw/<sub>/<file>`,**绝不**写含 `tests/fixtures/...` 或 `examples/...` 前缀的路径。
- **Node 兼容契约(F9 修复):** `engines.node = ">=20"`。**禁止**在 CLI 用 JSON import attributes(`import(x, { with: { type: 'json' } })`);读 JSON 用 CommonJS `node -e "const fs=require('fs'); ...JSON.parse(fs.readFileSync(...))"`。所有 stdin 脚本用 `node --input-type=module - <<'NODE'`(ESM 顶层 `import`/`await` 在 stdin 默认按 CJS 解析会失败)。
- 归属:README 直接链接 Karpathy 2026-04-04 Gist(`https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f`),注明 "inspired by, not affiliated with or endorsed by Andrej Karpathy"。
- **隐私措辞铁律:** **不得**声称"数据不出本机"。统一措辞:"文件默认存放在本地;被 Agent 读取的内容会发送给所配置的模型提供商。"
- **隐私机制契约(F6 修复,可执行):** 两个正交轴:
  - 仓库级 `config.storage.mode ∈ {local-only, private-git, public-git}`(用户声明,不靠 `git remote` 推断)。
  - 页面级 frontmatter `content_visibility ∈ {private, shareable}`。
  - 确定性 tracking 矩阵(setup 据 mode 重写 `.gitignore` 并对已跟踪内容执行 `git rm --cached`):

    | 路径 | local-only | private-git | public-git |
    |------|-----------|-------------|-----------|
    | `raw/**` | 忽略 | 跟踪(备份) | 忽略(公开库永不发布 raw) |
    | `wiki/**` 页面 + index/log | 忽略 | 跟踪 | 跟踪 |
    | `data/generated/**` | 忽略 | 忽略 | 忽略(可重建) |
    | `.karp-wiki/config.json`、templates、skill、docs、README | 跟踪 | 跟踪 | 跟踪 |
  - **public-git 硬门:** `kb.mjs check` 若发现**任何** `content_visibility: private` 页面即非零退出(私密内容请另建 local-only/private-git 库)。
  - **private-git 前置:** 需 `config.storage.remote_is_private_ack = true`,setup 明确警告"raw + wiki 摘要会推送到 remote"。
- frontmatter 契约(每页最小通用集,`schema_version: 1`):
  ```yaml
  ---
  schema_version: 1
  id: concept-spaced-repetition        # kebab-case,带类型前缀,全库唯一,创建后不变
  type: concept                         # concept | entity | source | output(四选一)
  subtype: ""                           # 领域细分,可空
  title: "间隔重复"
  summary: "用逐渐延长的复习间隔巩固记忆。"
  tags: ["learning"]
  source_ids: ["source-example"]        # 只能指向 source 页
  status: active                        # active | archived
  content_visibility: private           # private | shareable
  created_at: "2026-07-11"              # YYYY-MM-DD
  updated_at: "2026-07-11"
  ---
  ```
  - `source` 页额外:`media_type: text|image|audio`、`raw_path`(相对 KB 根)、`raw_sha256`(64-hex);`media_type: audio` 必须再带 `provenance`(如 `transcript-of-audio`,F8:不把转写伪装成原始音频)。
  - `output` 页额外:`query`。
- 文件名铁律:`<id>.md`。内链统一 `[[id]]`。
- `wiki/index.md` 是派生视图,由 `kb.mjs reindex` 重建,**Agent 不手工维护**。`wiki/log.md` 是 append-only 事件日志(Agent 追加),格式:`## [YYYY-MM-DD] ingest|query|lint | <标题>`。
- 通用类目:`wiki/concepts/ entities/ sources/ outputs/`。raw 子目录:`raw/text/ images/ audio/`。
- **fail-closed 规则:** `kb.mjs check` 与 `kb.mjs build-graph` 校验失败一律非零退出;`build-graph` 先校验、有错不写 graph。`kb.mjs reindex` **可**在未完全合规的库上运行(它是修复 index 漂移的工具,不阻塞)。
- 参考实现(只读借鉴):`~/Documents/english-learn-database/scripts/build-kb.mjs`。

## Task 3: 确定性内核 kb.mjs — 解析器 + validate + check(含安全约束、隐私门、--root)

> 解析/校验从参考实现 `english-learn-database/scripts/build-kb.mjs` 泛化。本任务修复 F1(相对 raw_path)、F2(`--root` + fail-fast)、F6(public-git 隐私门)、F7(无 frontmatter 报错、枚举、路径穿越/symlink、重复 SHA、数组类型)。

**Files:**
- Create: `scripts/kb.mjs`、`tests/kb.test.mjs`、`tests/helpers/tmp.mjs`
- Create: `tests/fixtures/good/**`(含真实 1×1 PNG)
- Create: `tests/fixtures/bad-yaml/`、`bad-dup-id/`、`bad-broken-link/`、`bad-missing-raw/`、`bad-no-frontmatter/`、`bad-traversal/`、`bad-enum/`、`bad-dup-sha/`

**Interfaces:**
- Produces(从 `scripts/kb.mjs` 导出):
  - 常量 `SCHEMA_VERSION`、`TYPES`、`REQUIRED_FIELDS`
  - `parseFrontmatter(text, filePath) → { frontmatter, body } | null`(unclosed 抛错)
  - `stripCodeBlocks(body) → string`、`extractWikiLinks(body) → string[]`、`sha256File(buf) → string`
  - `collectPages(wikiDir) → Promise<Page[]>`(容错:遇 malformed 跳过不抛;排除 index.md/log.md)

```javascript
#!/usr/bin/env node
// karp-wiki deterministic kernel. Zero external deps. Node >= 20.
import { readdir, readFile, writeFile, mkdir, realpath, stat } from 'node:fs/promises';
import { existsSync } from 'node:fs';
import { createHash } from 'node:crypto';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { execFileSync } from 'node:child_process';

export const SCHEMA_VERSION = 1;
export const TYPES = ['concept', 'entity', 'source', 'output'];
const TYPE_SET = new Set(TYPES);
export const REQUIRED_FIELDS = [
  'schema_version', 'id', 'type', 'title', 'summary',
  'tags', 'source_ids', 'status', 'content_visibility', 'created_at', 'updated_at',
];
const MEDIA_TYPES = new Set(['text', 'image', 'audio']);
const STATUS_VALUES = new Set(['active', 'archived']);
const VISIBILITY_VALUES = new Set(['private', 'shareable']);
const DATE_RE = /^\d{4}-\d{2}-\d{2}$/;
const SKIP_BASENAMES = new Set(['index.md', 'log.md']);

// Root order: --root > git toplevel > cwd (if it has wiki/) > null (CLI fail-fast).
// NO script-dir fallback (that was F2: tests ran against the wrong tree). cwd fallback is
// safe — it only triggers when cwd actually looks like a KB — and makes git optional for local-only.
export function resolveRoot(argvTail) {
  const i = argvTail.indexOf('--root');
  if (i !== -1 && argvTail[i + 1]) return path.resolve(argvTail[i + 1]);
  try { return execFileSync('git', ['rev-parse', '--show-toplevel'], { encoding: 'utf8' }).trim(); }
  catch { /* git absent or not a repo — fall through to cwd */ }
  const cwd = process.cwd();
  if (existsSync(path.join(cwd, 'wiki'))) return cwd;
  return null;
}

function stripQuotes(v) {
  if ((v.startsWith('"') && v.endsWith('"')) || (v.startsWith("'") && v.endsWith("'"))) return v.slice(1, -1);
  return v;
}
function parseScalar(value) {
  const t = value.trim();
  if (t === '[]') return [];
  if (t.startsWith('[') && t.endsWith(']')) {
    const inner = t.slice(1, -1).trim();
    if (!inner) return [];
    return inner.split(',').map((p) => stripQuotes(p.trim())).filter(Boolean);
  }
  if (t === 'true') return true;
  if (t === 'false') return false;
  if (/^-?\d+(\.\d+)?$/.test(t)) return Number(t);
  return stripQuotes(t);
}
export function parseFrontmatter(text, filePath) {
  if (!text.startsWith('---\n')) return null;
  const end = text.indexOf('\n---', 4);
  if (end === -1) throw new Error(`Unclosed frontmatter: ${filePath}`);
  const raw = text.slice(4, end);
  const body = text.slice(end + 4).replace(/^\r?\n/, '');
  const fm = {};
  for (const line of raw.split(/\r?\n/)) {
    if (!line.trim() || line.trim().startsWith('#')) continue;
    const sep = line.indexOf(':');
    if (sep === -1) continue;
    fm[line.slice(0, sep).trim()] = parseScalar(line.slice(sep + 1));
  }
  return { frontmatter: fm, body };
}
export function stripCodeBlocks(body) {
  return body.replace(/```[\s\S]*?```/g, '').replace(/`[^`]*`/g, '');
}
export function extractWikiLinks(body) {
  const clean = stripCodeBlocks(body);
  const out = [];
  const re = /\[\[([a-z0-9][a-z0-9-]*)\]\]/g;
  let m;
  while ((m = re.exec(clean)) !== null) out.push(m[1]);
  return out;
}
export function sha256File(buf) { return createHash('sha256').update(buf).digest('hex'); }

async function collectMarkdown(dir) {
  let entries;
  try { entries = await readdir(dir, { withFileTypes: true }); } catch { return []; }
  const files = [];
  for (const e of entries) {
    const full = path.join(dir, e.name);
    if (e.isDirectory()) files.push(...await collectMarkdown(full));
    else if (e.isFile() && e.name.endsWith('.md')) files.push(full);
  }
  return files;
}

export async function collectPages(wikiDir) {
  const files = (await collectMarkdown(wikiDir)).sort();
  const pages = [];
  for (const file of files) {
    if (SKIP_BASENAMES.has(path.basename(file))) continue;
    const text = await readFile(file, 'utf8');
    let parsed;
    try { parsed = parseFrontmatter(text, file); } catch { continue; } // malformed handled by findMalformed
    if (!parsed) continue;
    const fm = parsed.frontmatter;
    pages.push({
      file, basename: path.basename(file),
      id: fm.id, type: fm.type, title: fm.title, summary: fm.summary,
      tags: fm.tags, sourceIds: fm.source_ids,
      status: fm.status, contentVisibility: fm.content_visibility,
      mediaType: fm.media_type, rawPath: fm.raw_path, rawSha256: fm.raw_sha256,
      provenance: fm.provenance, query: fm.query, schemaVersion: fm.schema_version,
      body: parsed.body, frontmatter: fm, links: extractWikiLinks(parsed.body),
    });
  }
  return pages;
}

export async function findMalformed(wikiDir) {
  const files = (await collectMarkdown(wikiDir)).sort();
  const bad = [];
  for (const f of files) {
    if (SKIP_BASENAMES.has(path.basename(f))) continue;
    const text = await readFile(f, 'utf8');
    try { if (parseFrontmatter(text, f) === null) bad.push(f); }
    catch { bad.push(f); }
  }
  return bad;
}

export async function validate(pages, rootDir) {
  const errors = [];
  const add = (category, message) => errors.push({ category, message });
  const root = path.resolve(rootDir);
  const ids = new Set();
  const sourceIds = new Set(pages.filter((p) => p.type === 'source').map((p) => p.id));
  const shaMap = new Map();

  for (const p of pages) {
    const rel = path.relative(root, p.file);
    for (const f of REQUIRED_FIELDS) {
      const v = p.frontmatter[f];
      const missing = v === undefined || v === null ||
        (typeof v === 'string' && v.trim() === '') ||
        ((f === 'source_ids' || f === 'tags') && !Array.isArray(v));
      if (missing) add('missing_field', `${rel}: ${f}`);
    }
    if (p.schemaVersion !== SCHEMA_VERSION) add('schema_version', `${rel}: expected ${SCHEMA_VERSION}, got ${p.schemaVersion}`);
    if (!TYPE_SET.has(p.type)) add('invalid_type', `${rel}: ${p.type}`);
    if (p.status !== undefined && !STATUS_VALUES.has(p.status)) add('invalid_status', `${rel}: ${p.status}`);
    if (p.contentVisibility !== undefined && !VISIBILITY_VALUES.has(p.contentVisibility)) add('invalid_visibility', `${rel}: ${p.contentVisibility}`);
    for (const d of ['created_at', 'updated_at']) {
      const v = p.frontmatter[d];
      if (v !== undefined && !DATE_RE.test(String(v))) add('invalid_date', `${rel}: ${d}=${v}`);
    }
    if (p.tags !== undefined && !Array.isArray(p.tags)) add('type_error', `${rel}: tags must be an array`);
    if (p.sourceIds !== undefined && !Array.isArray(p.sourceIds)) add('type_error', `${rel}: source_ids must be an array`);
    if (p.id && p.basename !== `${p.id}.md`) add('filename', `${rel}: expected ${p.id}.md`);
    if (p.id) { if (ids.has(p.id)) add('duplicate_id', `${rel}: ${p.id}`); else ids.add(p.id); }
    for (const sid of (Array.isArray(p.sourceIds) ? p.sourceIds : [])) {
      if (!sourceIds.has(sid)) add('broken_source_ref', `${rel}: source_ids -> ${sid}`);
    }
    if (p.type === 'source') {
      if (!MEDIA_TYPES.has(p.mediaType)) add('media_type', `${rel}: ${p.mediaType}`);
      if (p.mediaType === 'audio' && (!p.provenance || String(p.provenance).trim() === '')) add('missing_field', `${rel}: provenance (audio must declare transcript provenance)`);
      if (!p.rawPath) add('raw_path', `${rel}: missing raw_path`);
      else {
        const abs = path.resolve(root, p.rawPath);
        if (abs !== root && !abs.startsWith(root + path.sep)) add('path_escape', `${rel}: raw_path escapes KB root -> ${p.rawPath}`);
        else {
          try {
            const real = await realpath(abs);
            if (real !== root && !real.startsWith(root + path.sep)) add('symlink_escape', `${rel}: raw_path resolves outside KB root`);
            else {
              const actual = sha256File(await readFile(real));
              if (!p.rawSha256) add('raw_hash', `${rel}: missing raw_sha256`);
              else if (p.rawSha256 !== actual) add('raw_hash', `${rel}: raw_sha256 mismatch`);
              if (p.rawSha256) {
                if (shaMap.has(p.rawSha256)) add('duplicate_raw', `${shaMap.get(p.rawSha256)} <-> ${rel}`);
                else shaMap.set(p.rawSha256, rel);
              }
            }
          } catch { add('raw_missing', `${rel}: raw file not found ${p.rawPath}`); }
        }
      }
    }
    if (p.type === 'output') {
      const q = p.query;
      if (q === undefined || q === null || String(q).trim() === '') add('missing_field', `${rel}: query`);
    }
  }
  for (const p of pages) for (const link of p.links) if (!ids.has(link)) add('broken_link', `${path.relative(root, p.file)}: [[${link}]]`);
  return errors;
}

export function parseIndexIds(text) {
  const out = [];
  const re = /^-\s+\[\[([a-z0-9][a-z0-9-]*)\]\]/gm;
  let m;
  while ((m = re.exec(text)) !== null) out.push(m[1]);
  return out;
}
export function indexCoverageErrors(pages, indexText) {
  const pageIds = new Set(pages.map((p) => p.id).filter(Boolean));
  const indexIds = new Set(parseIndexIds(indexText));
  const errors = [];
  for (const id of pageIds) if (!indexIds.has(id)) errors.push({ category: 'index_missing', message: `index.md missing ${id}` });
  for (const id of indexIds) if (!pageIds.has(id)) errors.push({ category: 'index_stale', message: `index.md lists unknown ${id}` });
  return errors;
}
export function visibilityErrors(pages, mode) {
  if (mode !== 'public-git') return [];
  return pages.filter((p) => p.contentVisibility === 'private')
    .map((p) => ({ category: 'visibility_leak', message: `${p.id}: private page not allowed in public-git mode (set content_visibility: shareable or use a private KB)` }));
}

async function readConfigMode(root) {
  try {
    const cfg = JSON.parse(await readFile(path.join(root, '.karp-wiki', 'config.json'), 'utf8'));
    return cfg?.storage?.mode ?? 'local-only';
  } catch { return 'local-only'; }
}
function printErrors(errors) {
  const byCat = {};
  for (const e of errors) (byCat[e.category] ??= []).push(e.message);
  for (const [cat, msgs] of Object.entries(byCat)) {
    console.error(`\n${cat} (${msgs.length}):`);
    for (const msg of msgs) console.error(`  - ${msg}`);
  }
}

async function cmdCheck(root) {
  const wikiDir = path.join(root, 'wiki');
  const pages = await collectPages(wikiDir);
  const errors = await validate(pages, root);
  for (const f of await findMalformed(wikiDir)) errors.push({ category: 'no_frontmatter', message: path.relative(root, f) });
  let indexText = '';
  try { indexText = await readFile(path.join(wikiDir, 'index.md'), 'utf8'); } catch { /* no index yet */ }
  errors.push(...indexCoverageErrors(pages, indexText));
  errors.push(...visibilityErrors(pages, await readConfigMode(root)));
  if (errors.length) {
    printErrors(errors);
    console.error(`\n✗ check failed: ${errors.length} error(s) across ${pages.length} page(s)`);
    process.exitCode = 1;
    return;
  }
  console.log(`✓ check passed: ${pages.length} page(s)`);
}

export function buildGraph(pages) {
  const nodes = pages.filter((p) => p.id)
    .map((p) => ({ id: p.id, type: p.type, title: p.title }))
    .sort((a, b) => a.id.localeCompare(b.id));
  const seen = new Set();
  const edges = [];
  const push = (from, to, relation) => {
    if (!from || !to) return;
    const key = `${from}|${to}|${relation}`;
    if (seen.has(key)) return;
    seen.add(key);
    edges.push({ from, to, relation });
  };
  for (const p of pages) {
    for (const sid of (Array.isArray(p.sourceIds) ? p.sourceIds : [])) push(p.id, sid, 'derived_from');
    for (const link of p.links) push(p.id, link, 'links_to');
  }
  edges.sort((a, b) => (a.from + a.to + a.relation).localeCompare(b.from + b.to + b.relation));
  return { schema_version: SCHEMA_VERSION, nodes, edges };
}
async function cmdBuildGraph(root) {
  const wikiDir = path.join(root, 'wiki');
  const pages = await collectPages(wikiDir);
  const errors = await validate(pages, root);
  for (const f of await findMalformed(wikiDir)) errors.push({ category: 'no_frontmatter', message: path.relative(root, f) });
  errors.push(...visibilityErrors(pages, await readConfigMode(root)));
  if (errors.length) {
    printErrors(errors);
    console.error(`\n✗ build-graph aborted (fail-closed): ${errors.length} error(s)`);
    process.exitCode = 1;
    return;
  }
  const graph = buildGraph(pages);
  const outDir = path.join(root, 'data', 'generated');
  await mkdir(outDir, { recursive: true });
  await writeFile(path.join(outDir, 'graph.json'), `${JSON.stringify(graph, null, 2)}\n`, 'utf8');

}

async function walk(dir) {
  let entries;
  try { entries = await readdir(dir, { withFileTypes: true }); } catch { return []; }
  const out = [];
  for (const e of entries) {
    const full = path.join(dir, e.name);
    if (e.isDirectory()) out.push(...await walk(full));
    else if (e.isFile()) out.push(full);
  }
  return out;
}

export async function syncSkills({ root, check = false } = {}) {
  if (!root) { root = repoRoot(); if (!root) throw new Error('Cannot determine repo root; pass { root }.'); }
  const srcDir = path.join(root, CANONICAL);
  const srcFiles = (await walk(srcDir)).sort();
  if (srcFiles.length === 0) throw new Error(`canonical skill is missing or empty: ${CANONICAL}`);
  const drift = [];
  const mirrors = MIRRORS.map((m) => path.join(root, m));
  const srcRel = srcFiles.map((f) => path.relative(srcDir, f)).sort();

  for (const mirrorAbs of mirrors) {
    if (!check) await rm(mirrorAbs, { recursive: true, force: true });
    for (const srcFile of srcFiles) {
      const rel = path.relative(srcDir, srcFile);
      const destFile = path.join(mirrorAbs, rel);
      const srcBuf = await readFile(srcFile);
      if (check) {
        let destBuf;
        try { destBuf = await readFile(destFile); }
        catch { drift.push(`${path.relative(root, destFile)}: missing`); continue; }
        if (!srcBuf.equals(destBuf)) drift.push(`${path.relative(root, destFile)}: differs`);
      } else {
        await mkdir(path.dirname(destFile), { recursive: true });
        await writeFile(destFile, srcBuf);
      }
    }
    if (check) {
      for (const f of await walk(mirrorAbs)) {
        const rel = path.relative(mirrorAbs, f);
        if (!srcRel.includes(rel)) drift.push(`${path.join(path.relative(root, mirrorAbs), rel)}: extra`);
      }
    }
  }
  return { mirrors, drift, sourceFileCount: srcFiles.length };
}

if (process.argv[1] && fileURLToPath(import.meta.url) === path.resolve(process.argv[1])) {
  const check = process.argv.includes('--check');
  syncSkills({ check }).then(({ drift, sourceFileCount }) => {
    if (check) {
      if (drift.length) {
        console.error('✗ skill mirrors out of sync:');
        for (const d of drift) console.error(`  - ${d}`);
        console.error('Run `npm run sync-skills` to regenerate.');
        process.exitCode = 1;
      } else console.log(`✓ skill mirrors in sync (${sourceFileCount} files)`);
    } else console.log(`✓ synced ${sourceFileCount} files to ${MIRRORS.join(', ')}`);
  }).catch((err) => { console.error(err.message); process.exitCode = 1; });
}
```
