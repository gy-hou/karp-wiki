> **This plan supersedes `2026-07-10-karp-wiki.md`.** It rewrites v1 after a Codex review corrected six premises. Do **not** execute the old plan's Task 0 (repo migration) — it is already done and its paths no longer exist.

**Goal:** 把已迁移完成的 `karp-wiki` 仓库做成一个可公开发布的通用本地知识库模板:Claude Code 与 Codex **双端 native skill** 自动发现、纯 Markdown 资产、一份最小确定性内核脚本保证幂等与可校验、支持文本/真实图片/音频转写录入。

**Architecture:** Karpathy 三层模型(`raw/` append-only → `wiki/` LLM 维护 → `AGENTS.md`/`CLAUDE.md` 规范)。规范唯一正文是 `AGENTS.md`,`CLAUDE.md` 用官方 `@AGENTS.md` 导入。一份 canonical Agent Skill 存放在 `skills/kb-setup/`,由 `scripts/sync-skills.mjs` 生成 `.claude/skills/kb-setup/` 与 `.agents/skills/kb-setup/` 两份**字节一致**的发现镜像(CI 校验)。状态由 `.karp-wiki/config.json`(`not_started → in_progress → complete`)驱动,setup 幂等。确定性内核 `scripts/kb.mjs` 提供 `check / reindex / build-graph`,校验失败非零退出;可视化 UI 留到 v2,但 v1 就产出可消费的 `graph.json`。

**Tech Stack:** 纯 Markdown + YAML frontmatter;Node ≥ 18(仅标准库,零外部依赖);Node 内置 `node --test`;`git`(状态/remote 检测);可选 `rg`。目标运行时 Claude Code / Codex。

## Global Constraints

- 产品/仓库名:**karp-wiki**(定位:公开开源发布,GitHub Template)。
- 从**当前已迁移基线**开始;不复制/删除旧 `chatgpt-advanced-prompts` 路径(已不存在)。脚本一律用 `git rev-parse --show-toplevel` 定位根目录并 fail fast,**禁止硬编码用户绝对路径**。
- 语言:中文为主 + 英文兼容(README 双份;目录名/字段名用英文)。
- `raw/` = **append-only**(可新增文件;落盘后 Agent 不得修改或删除其内容)。
- 归属:README 直接链接 Karpathy 2026-04-04 Gist(`https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f`),并注明 "inspired by, not affiliated with or endorsed by Andrej Karpathy"。
- 隐私措辞铁律:**不得**声称"数据不出本机"。统一措辞:"文件默认存放在本地;被 Agent 读取的内容会发送给所配置的模型提供商。"
- frontmatter 契约(每页最小通用集,`schema_version: 1`):
  ```yaml
  ---
  schema_version: 1
  id: concept-spaced-repetition        # kebab-case,带类型前缀,全库唯一,创建后不变
  type: concept                         # concept | entity | source | output(四选一)
  subtype: ""                           # 领域细分,可空
  title: "间隔重复"
  summary: "用逐渐延长的复习间隔巩固记忆。"
  tags: ["learning"]
  source_ids: ["source-example"]        # 只能指向 source 页
  status: active                        # active | archived
  visibility: private                   # private | shareable
  created_at: "2026-07-11"
  updated_at: "2026-07-11"
  ---
  ```
  - `source` 页额外:`media_type: text|image|audio`、`raw_path`、`raw_sha256`(64-hex)。
  - `output` 页额外:`query`。
- 文件名铁律:`<id>.md`。内链统一 `[[id]]`。
- `wiki/index.md` 是 frontmatter 的**派生视图**,由 `kb.mjs reindex` 重建,**Agent 不手工维护**。`wiki/log.md` 是 append-only 事件日志,由 Agent 追加,格式:`## [YYYY-MM-DD] ingest|query|lint | <标题>`。
- 通用类目:`wiki/concepts/ entities/ sources/ outputs/`。raw 子目录:`raw/text/ images/ audio/`。
- 校验失败一律非零退出(`kb.mjs check`)。
- 参考实现(只读借鉴,不修改):`~/Documents/english-learn-database/scripts/build-kb.mjs`。

- [ ] **Step 5: 写 `skills/kb-setup/references/schema.md`**

必含以下小节与内容(逐字给出契约,不留 TBD):
- **通用 frontmatter 表**:字段 / 类型 / 是否必填 / 说明。必填字段:`schema_version(=1)`、`id`、`type`、`title`、`summary`、`tags`、`source_ids`、`status`、`visibility`、`created_at`、`updated_at`。
- **ID 规则**:kebab-case + 类型前缀(`concept-`/`entity-`/`source-`/`output-`);全库唯一;创建后不变;文件名必须等于 `<id>.md`。
- **type 白名单**:`concept | entity | source | output`。领域细分用 `subtype` 或 `tags`,**不得新增顶层 type**。
- **source 额外字段**:`media_type ∈ {text,image,audio}`、`raw_path`(相对 repo root)、`raw_sha256`(raw 文件的 sha256,64-hex)。
- **output 额外字段**:`query`。
- **status/visibility 取值**:`status: active | archived`;`visibility: private | shareable`。
- **index/log 契约**:`index.md` 每行 `- [[id]] — summary`,由 `kb.mjs reindex` 生成;`log.md` 每条 `## [YYYY-MM-DD] ingest|query|lint | <标题>`,append-only。
- **graph 边契约(v1 冻结)**:
  - 节点:每个内容页 → `{ id, type, title }`(排除 index/log/templates)。
  - 边 1:`source_ids` 中每个 sid → `{ from: <page id>, to: <sid>, relation: "derived_from" }`。
  - 边 2:正文 `[[target]]`(排除 frontmatter 与代码块)→ `{ from: <page id>, to: <target>, relation: "links_to" }`。
  - 去重键:`(from, to, relation)`。
  - 输出:`data/generated/graph.json`,含 `schema_version`、排序稳定的 `nodes`、`edges`。

#!/usr/bin/env node
// karp-wiki deterministic kernel. Zero external deps. Node >= 18.
import { readdir, readFile, writeFile, mkdir } from 'node:fs/promises';
import { createHash } from 'node:crypto';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { execFileSync } from 'node:child_process';

export const SCHEMA_VERSION = 1;
export const TYPES = ['concept', 'entity', 'source', 'output'];
const TYPE_SET = new Set(TYPES);
export const REQUIRED_FIELDS = [
  'schema_version', 'id', 'type', 'title', 'summary',
  'tags', 'source_ids', 'status', 'visibility', 'created_at', 'updated_at',
];
const MEDIA_TYPES = new Set(['text', 'image', 'audio']);

export function repoRoot() {
  try {
    return execFileSync('git', ['rev-parse', '--show-toplevel'], { encoding: 'utf8' }).trim();
  } catch {
    return path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..');
  }
}

function stripQuotes(v) {
  if ((v.startsWith('"') && v.endsWith('"')) || (v.startsWith("'") && v.endsWith("'"))) {
    return v.slice(1, -1);
  }
  return v;
}

function parseScalar(value) {
  const t = value.trim();
  if (t === '[]') return [];
  if (t.startsWith('[') && t.endsWith(']')) {
    const inner = t.slice(1, -1).trim();
    if (!inner) return [];
    return inner.split(',').map((p) => stripQuotes(p.trim())).filter(Boolean);
  }
  if (t === 'true') return true;
  if (t === 'false') return false;
  if (/^-?\d+(\.\d+)?$/.test(t)) return Number(t);
  return stripQuotes(t);
}

export function parseFrontmatter(text, filePath) {
  if (!text.startsWith('---\n')) return null;
  const end = text.indexOf('\n---', 4);
  if (end === -1) throw new Error(`Unclosed frontmatter: ${filePath}`);
  const raw = text.slice(4, end);
  const body = text.slice(end + 4).replace(/^\r?\n/, '');
  const fm = {};
  for (const line of raw.split(/\r?\n/)) {
    if (!line.trim() || line.trim().startsWith('#')) continue;
    const sep = line.indexOf(':');
    if (sep === -1) continue;
    fm[line.slice(0, sep).trim()] = parseScalar(line.slice(sep + 1));
  }
  return { frontmatter: fm, body };
}

export function stripCodeBlocks(body) {
  return body.replace(/```[\s\S]*?```/g, '').replace(/`[^`]*`/g, '');
}

export function extractWikiLinks(body) {
  const clean = stripCodeBlocks(body);
  const out = [];
  const re = /\[\[([a-z0-9][a-z0-9-]*)\]\]/g;
  let m;
  while ((m = re.exec(clean)) !== null) out.push(m[1]);
  return out;
}

export function sha256File(buf) {
  return createHash('sha256').update(buf).digest('hex');
}

async function collectMarkdown(dir) {
  let entries;
  try { entries = await readdir(dir, { withFileTypes: true }); }
  catch { return []; }
  const files = [];
  for (const e of entries) {
    const full = path.join(dir, e.name);
    if (e.isDirectory()) files.push(...await collectMarkdown(full));
    else if (e.isFile() && e.name.endsWith('.md')) files.push(full);
  }
  return files;
}

const SKIP_BASENAMES = new Set(['index.md', 'log.md']);

export async function collectPages(wikiDir) {
  const files = (await collectMarkdown(wikiDir)).sort();
  const pages = [];
  for (const file of files) {
    if (SKIP_BASENAMES.has(path.basename(file))) continue;
    const text = await readFile(file, 'utf8');
    const parsed = parseFrontmatter(text, file);
    if (!parsed) continue;
    const fm = parsed.frontmatter;
    pages.push({
      file,
      basename: path.basename(file),
      id: fm.id,
      type: fm.type,
      title: fm.title,
      summary: fm.summary,
      tags: Array.isArray(fm.tags) ? fm.tags : [],
      sourceIds: Array.isArray(fm.source_ids) ? fm.source_ids : [],
      status: fm.status,
      visibility: fm.visibility,
      mediaType: fm.media_type,
      rawPath: fm.raw_path,
      rawSha256: fm.raw_sha256,
      query: fm.query,
      schemaVersion: fm.schema_version,
      body: parsed.body,
      frontmatter: fm,
      links: extractWikiLinks(parsed.body),
    });
  }
  return pages;
}

export async function validate(pages, rootDir) {
  const errors = [];
  const add = (category, message) => errors.push({ category, message });
  const ids = new Set();
  const sourceIds = new Set(pages.filter((p) => p.type === 'source').map((p) => p.id));

  for (const p of pages) {
    const rel = path.relative(rootDir, p.file);
    for (const f of REQUIRED_FIELDS) {
      const v = p.frontmatter[f];
      const missing =
        v === undefined || v === null ||
        (typeof v === 'string' && v.trim() === '') ||
        ((f === 'source_ids' || f === 'tags') && !Array.isArray(v));
      if (missing) add('missing_field', `${rel}: ${f}`);
    }
    if (p.schemaVersion !== SCHEMA_VERSION) {
      add('schema_version', `${rel}: expected ${SCHEMA_VERSION}, got ${p.schemaVersion}`);
    }
    if (!TYPE_SET.has(p.type)) add('invalid_type', `${rel}: ${p.type}`);
    if (p.id && p.basename !== `${p.id}.md`) add('filename', `${rel}: expected ${p.id}.md`);
    if (p.id) {
      if (ids.has(p.id)) add('duplicate_id', `${rel}: ${p.id}`);
      else ids.add(p.id);
    }
    for (const sid of p.sourceIds) {
      if (!sourceIds.has(sid)) add('broken_source_ref', `${rel}: source_ids -> ${sid}`);
    }
    if (p.type === 'source') {
      if (!MEDIA_TYPES.has(p.mediaType)) add('media_type', `${rel}: ${p.mediaType}`);
      if (!p.rawPath) add('raw_path', `${rel}: missing raw_path`);
      else {
        try {
          const buf = await readFile(path.resolve(rootDir, p.rawPath));
          const actual = sha256File(buf);
          if (!p.rawSha256) add('raw_hash', `${rel}: missing raw_sha256`);
          else if (p.rawSha256 !== actual) add('raw_hash', `${rel}: raw_sha256 mismatch`);
        } catch {
          add('raw_missing', `${rel}: raw file not found ${p.rawPath}`);
        }
      }
    }
    if (p.type === 'output') {
      const q = p.query;
      if (q === undefined || q === null || String(q).trim() === '') add('missing_field', `${rel}: query`);
    }
  }
  for (const p of pages) {
    for (const link of p.links) {
      if (!ids.has(link)) add('broken_link', `${path.relative(rootDir, p.file)}: [[${link}]]`);
    }
  }
  return errors;
}

export function parseIndexIds(text) {
  const out = [];
  const re = /^-\s+\[\[([a-z0-9][a-z0-9-]*)\]\]/gm;
  let m;
  while ((m = re.exec(text)) !== null) out.push(m[1]);
  return out;
}

export function indexCoverageErrors(pages, indexText, _rootDir) {
  const pageIds = new Set(pages.map((p) => p.id).filter(Boolean));
  const indexIds = new Set(parseIndexIds(indexText));
  const errors = [];
  for (const id of pageIds) if (!indexIds.has(id)) errors.push({ category: 'index_missing', message: `index.md missing ${id}` });
  for (const id of indexIds) if (!pageIds.has(id)) errors.push({ category: 'index_stale', message: `index.md lists unknown ${id}` });
  return errors;
}

async function cmdCheck(root) {
  const wikiDir = path.join(root, 'wiki');
  const pages = await collectPages(wikiDir);
  const errors = await validate(pages, root);
  let indexText = '';
  try { indexText = await readFile(path.join(wikiDir, 'index.md'), 'utf8'); } catch { /* no index yet */ }
  errors.push(...indexCoverageErrors(pages, indexText, root));
  if (errors.length) {
    const byCat = {};
    for (const e of errors) (byCat[e.category] ??= []).push(e.message);
    for (const [cat, msgs] of Object.entries(byCat)) {
      console.error(`\n${cat} (${msgs.length}):`);
      for (const msg of msgs) console.error(`  - ${msg}`);
    }
    console.error(`\n✗ check failed: ${errors.length} error(s) across ${pages.length} page(s)`);
    process.exitCode = 1;
    return;
  }
  console.log(`✓ check passed: ${pages.length} page(s)`);
}

const COMMANDS = { check: cmdCheck };

if (process.argv[1] && fileURLToPath(import.meta.url) === path.resolve(process.argv[1])) {
  const cmd = process.argv[2];
  const fn = COMMANDS[cmd];
  if (!fn) {
    console.error('Usage: node scripts/kb.mjs <check|reindex|build-graph>');
    process.exitCode = 2;
  } else {
    fn(repoRoot()).catch((err) => { console.error(err.message); process.exitCode = 1; });
  }
}

export function buildGraph(pages) {
  const nodes = pages
    .filter((p) => p.id)
    .map((p) => ({ id: p.id, type: p.type, title: p.title }))
    .sort((a, b) => a.id.localeCompare(b.id));
  const seen = new Set();
  const edges = [];
  const push = (from, to, relation) => {
    if (!from || !to) return;
    const key = `${from}|${to}|${relation}`;
    if (seen.has(key)) return;
    seen.add(key);
    edges.push({ from, to, relation });
  };
  for (const p of pages) {
    for (const sid of p.sourceIds) push(p.id, sid, 'derived_from');
    for (const link of p.links) push(p.id, link, 'links_to');
  }
  edges.sort((a, b) => (a.from + a.to + a.relation).localeCompare(b.from + b.to + b.relation));
  return { schema_version: SCHEMA_VERSION, nodes, edges };
}

async function cmdBuildGraph(root) {
  const pages = await collectPages(path.join(root, 'wiki'));
  const graph = buildGraph(pages);
  const outDir = path.join(root, 'data', 'generated');
  await mkdir(outDir, { recursive: true });
  await writeFile(path.join(outDir, 'graph.json'), `${JSON.stringify(graph, null, 2)}\n`, 'utf8');
  console.log(`✓ build-graph: ${graph.nodes.length} node(s), ${graph.edges.length} edge(s) -> data/generated/graph.json`);
}

```javascript
#!/usr/bin/env node
// Generate byte-identical discovery mirrors of the canonical kb-setup skill.
// Canonical: skills/kb-setup/  ->  .claude/skills/kb-setup/ and .agents/skills/kb-setup/
import { readdir, readFile, writeFile, mkdir, rm } from 'node:fs/promises';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { execFileSync } from 'node:child_process';

function repoRoot() {
  try { return execFileSync('git', ['rev-parse', '--show-toplevel'], { encoding: 'utf8' }).trim(); }
  catch { return path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..'); }
}

const MIRRORS = ['.claude/skills/kb-setup', '.agents/skills/kb-setup'];
const CANONICAL = 'skills/kb-setup';

async function walk(dir) {
  let entries;
  try { entries = await readdir(dir, { withFileTypes: true }); } catch { return []; }
  const out = [];
  for (const e of entries) {
    const full = path.join(dir, e.name);
    if (e.isDirectory()) out.push(...await walk(full));
    else if (e.isFile()) out.push(full);
  }
  return out;
}

export async function syncSkills({ check = false } = {}) {
  const root = repoRoot();
  const srcDir = path.join(root, CANONICAL);
  const srcFiles = (await walk(srcDir)).sort();
  const drift = [];
  const mirrors = MIRRORS.map((m) => path.join(root, m));

  for (const mirrorAbs of mirrors) {
    if (!check) { await rm(mirrorAbs, { recursive: true, force: true }); }
    for (const srcFile of srcFiles) {
      const relFromSrc = path.relative(srcDir, srcFile);
      const destFile = path.join(mirrorAbs, relFromSrc);
      const srcBuf = await readFile(srcFile);
      if (check) {
        let destBuf;
        try { destBuf = await readFile(destFile); } catch { drift.push(`${path.relative(root, destFile)}: missing`); continue; }
        if (!srcBuf.equals(destBuf)) drift.push(`${path.relative(root, destFile)}: differs`);
      } else {
        await mkdir(path.dirname(destFile), { recursive: true });
        await writeFile(destFile, srcBuf);
      }
    }
    if (check) {
      const destFiles = (await walk(mirrorAbs)).map((f) => path.relative(mirrorAbs, f)).sort();
      const srcRel = srcFiles.map((f) => path.relative(srcDir, f)).sort();
      for (const extra of destFiles) if (!srcRel.includes(extra)) drift.push(`${path.join(path.relative(root, mirrorAbs), extra)}: extra`);
    }
  }
  return { mirrors, drift, sourceFileCount: srcFiles.length };
}

if (process.argv[1] && fileURLToPath(import.meta.url) === path.resolve(process.argv[1])) {
  const check = process.argv.includes('--check');
  syncSkills({ check }).then(({ drift, sourceFileCount }) => {
    if (check) {
      if (drift.length) {
        console.error('✗ skill mirrors out of sync:');
        for (const d of drift) console.error(`  - ${d}`);
        console.error('Run `npm run sync-skills` to regenerate.');
        process.exitCode = 1;
      } else {
        console.log(`✓ skill mirrors in sync (${sourceFileCount} files)`);
      }
    } else {
      console.log(`✓ synced ${sourceFileCount} files to ${MIRRORS.join(', ')}`);
    }
  }).catch((err) => { console.error(err.message); process.exitCode = 1; });
}
```
